# v1.0 Polish Plan — three-pass implementation guide

This document is the spec for taking the Bioassay Suite from v0.9 to v1.0.0.
It is split into three independent PRs. **Each PR must pass review before the
next one starts.** Do not bundle multiple PRs into one — the alignment saga
showed why that fails.

Each PR section lists:
1. **Goal** — what the user should perceive after the PR ships.
2. **Files** — what to touch.
3. **Changes** — concrete instructions, in implementation order.
4. **Out of scope** — what NOT to touch, with reasons.
5. **Verification** — what to screenshot / click to confirm it works.

Bump the CSS sentinel after each PR: `v10`, `v11`, `v12`. Confirm the new
sentinel logs in the browser console before declaring done.

#### 1.4 Tab 4 — live weighting preview (the substance)

Goal: replace the empty white space on the right of Tab 4 with a small

##### (a) Create `server/server_analysis.R`

```r
server_analysis <- function(input, output, session) {

  output$weighting_preview <- renderPlot({
    weights <- input$regression_weight
    if (is.null(weights) || length(weights) == 0) return(NULL)

    # Synthetic 4PL standards — fixed, not user data
    log_x <- seq(-10, -5, length.out = 8)
    x     <- 10 ^ log_x
    # 4PL with bottom=5, top=95, ec50=1e-7, hill=1
    y_true <- 5 + (95 - 5) / (1 + (x / 1e-7) ^ 1)
    set.seed(42)
    # heteroscedastic noise (variance grows with y)
    y_obs <- y_true + rnorm(8, 0, sd = y_true * 0.05)

    # Color per weighting (must match the four checkbox values)
    colors <- c(none = "#1f3a5f", inv_y = "#009E73",
                inv_y2 = "#D97757", auto = "#9966CC")

    par(mar = c(4, 4, 1.5, 1), cex.axis = 0.85, cex.lab = 0.9)
    plot(log_x, y_obs, pch = 19, cex = 1.1, col = "#444",
         xlab = "log(concentration)", ylab = "%B/B0",
         ylim = c(0, 100), bty = "n")

    # Draw one fitted curve per ticked weighting
    fine_x <- seq(min(log_x), max(log_x), length.out = 200)
    for (w in weights) {
      # Fake the visual difference — real fitting not needed for preview.
      # Each weighting curve gets a slight shift in EC50 / slope to show
      # that the weighting choice changes the fit.
      shift <- switch(w,
                      none   = c(ec50 = 1.0e-7, hill = 1.00),
                      inv_y  = c(ec50 = 1.1e-7, hill = 1.05),
                      inv_y2 = c(ec50 = 0.9e-7, hill = 1.15),
                      auto   = c(ec50 = 1.0e-7, hill = 1.10))
      fine_y <- 5 + (95 - 5) / (1 + (10 ^ fine_x / shift["ec50"]) ^ shift["hill"])
      lines(fine_x, fine_y, col = colors[[w]], lwd = 2)
    }
    legend("topright", legend = weights, col = colors[weights],
           lwd = 2, bty = "n", cex = 0.85)
  }, height = 280)
}
```

Behaviour script (place alongside the existing `tags$script` blocks):

```js
$(function() {
  var $toggle  = $('#bs-lang-toggle');
  var $pop     = $('#bs-lang-popover');
  var $current = $('#bs-lang-current');
  var labels   = { en: 'EN', es: 'ES', fr: 'FR', ru: 'RU', zh: 'ZH' };

  function syncLabel() {
    var v = $('#app_language').val();
    if (v && labels[v]) $current.text(labels[v]);
    $pop.find('.bs-lang-option').each(function() {
      $(this).toggleClass('is-active', $(this).data('lang') === v);
    });
  }

  $toggle.on('click', function(e) {
    e.stopPropagation();
    var open = $pop.toggleClass('is-open').hasClass('is-open');
    $toggle.attr('aria-expanded', open);
  });

  $(document).on('click', function(e) {
    if (!$.contains($pop[0], e.target) && e.target !== $toggle[0]) {
      $pop.removeClass('is-open');
      $toggle.attr('aria-expanded', 'false');
    }
  });

  $pop.on('click', '.bs-lang-option', function() {
    var lang = $(this).data('lang');
    var $sel = $('#app_language');
    $sel.val(lang).trigger('change');
    $pop.removeClass('is-open');
    $toggle.attr('aria-expanded', 'false');
    syncLabel();
  });

  $(document).on('change', '#app_language', syncLabel);
  syncLabel();
});
```
